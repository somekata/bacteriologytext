腸内細菌目（Enterobacterales）

以前の「腸内細菌科」から遺伝子解析を経て「目」に格上げされた。グラム陰性桿菌の中で最も種類が多く、 医療現場で毎日遭遇する最重要グループ。

共通する特徴

  • 通性嫌気性（酸素の有無にかかわらず発育）。
  • ブドウ糖を発酵して酸を産生する。
  • オキシダーゼ陰性（ビブリオ科・エロモナス科との最大の鑑別点）。
  • ほとんどが腸管内に常在 or 腸管を介して伝播する。

誘導型AmpCを持つ菌（要注意）

  • Enterobacter cloacae complex、Klebsiella aerogenes、 Citrobacter freundii、Serratia marcescens など。
  • 第三世代セフェム系抗菌薬の投与中にAmpCが過剰産生され、治療中に耐性化することがある。
  • 重症例ではセフェピムやカルバペネム系抗菌薬を検討（感受性と施設指針に従う）。

主要菌のショートノート

Escherichia coli
（大腸菌）

  • 尿路感染症（膀胱炎・腎盂腎炎）の原因菌第1位。
  • 敗血症、胆道感染症、新生児髄膜炎など。
  • 下痢原性大腸菌（EHEC、ETEC、EPEC、EIEC、EAEC）が食中毒・腸炎を起こす。
  • EHEC（腸管出血性大腸菌：O157 など）：志賀毒素（Stx）産生 → 溶血性尿毒症症候群（HUS）。 3類。

Klebsiella pneumoniae
（肺炎桿菌）

  • 健常者の腸内にも存在。免疫低下者の肺炎・尿路感染・院内感染。
  • 厚い莢膜（ムコイド状のコロニー）が特徴。
  • 高病原性株（hvKp）は肝膿瘍・眼内炎・髄膜炎など転移性病変を起こすことがある。
  • アンピシリンに自然耐性。

Proteus mirabilis など
（変形菌）

  • ウレアーゼ産生 → 尿をアルカリ化。
  • 尿路結石（ストルバイト結石）や、カテーテル関連尿路感染の原因に。
  • 寒天上で遊走（swarming）する。

Salmonella / Shigella / Yersinia

  • Salmonella Typhi / Paratyphi：腸チフス・パラチフス（3類）。 非チフス性Salmonellaは食中毒。
  • Shigella：細菌性赤痢（3類）。少量の菌で感染する。
  • Yersinia enterocolitica は腸炎、Y. pestis はペスト（1類）。

最も警戒される耐性菌：ESBL・CRE／CPE

腸内細菌目は抗菌薬の使用圧のもとで、β-ラクタム系抗菌薬を分解する酵素（β-ラクタマーゼ）の遺伝子を獲得して耐性化してきた。 多くはプラスミド上にあり、菌種を越えて伝播する。

① ESBL産生菌（拡張型β-ラクタマーゼ産生菌）

  • ペニシリン系、第一〜第三（・第四）世代セフェム系、アズトレオナムを分解する。 セファマイシン系・カルバペネム系は基本的に分解しない。
  • 市中の膀胱炎でもE. coliのESBL産生率が上昇している。
  • 重症感染症の治療ではカルバペネム系抗菌薬を用いることが多い。
  • 試験管内ではクラブラン酸などβ-ラクタマーゼ阻害薬で阻害される。

② CRE（カルバペネム耐性腸内細菌目細菌）／ CPE（カルバペネマーゼ産生腸内細菌目細菌）

  • CRE：カルバペネム系抗菌薬に耐性を示す腸内細菌目。 感染症法上5類全数把握（基準は厚労省資料で確認）。
  • CPE：CREのうち、カルバペネムを直接分解する酵素（カルバペネマーゼ）の遺伝子を持つもの。 プラスミドで他菌種へ伝播するため、院内感染対策上、特に厳重な対応が必要。
  • 使える抗菌薬が限られ、「悪夢の耐性菌（nightmare bacteria）」と呼ばれる。

β-ラクタマーゼの Ambler分類

β-ラクタマーゼをアミノ酸配列（構造）に基づいてA〜Dの4クラスに分ける分類。 活性中心にセリンを持つセリン酵素（A・C・D）と、亜鉛を必要とする金属酵素（B：MBL）に大別される。

クラス 酵素の性質 代表的な酵素 主な特徴・基質
A セリン酵素 CTX-M（ESBL）、TEM・SHV（ESBLを含む）、KPC（カルバペネマーゼ） ペニシリン系・セフェム系を分解。KPCはカルバペネム系・アズトレオナムも分解。
B 金属酵素（亜鉛、MBL） IMP、NDM、VIM カルバペネム系を強力に分解。アズトレオナムは分解しない。EDTAで阻害される。
C セリン酵素 AmpC（染色体性／プラスミド性） 第三世代セフェム系やセファマイシン系までを分解。クラブラン酸では阻害されにくい。
D セリン酵素 OXA型（例：OXA-48） オキサシリンを分解。一部はカルバペネマーゼとして働く。

CTX-M（クラスA）

  • ESBLの中で世界的・国内でも主要。
  • 名称は「セフォタキシム（CTX）を良く分解する酵素（Munich で報告）」に由来。
  • E. coli・K. pneumoniae が持つことが多い。

KPC（クラスA）

  • Klebsiella pneumoniae carbapenemase の略。
  • 米国・欧州・中国などで多い。日本国内の検出は少ないが、海外からの持ち込みに警戒。
  • ほぼ全てのβ-ラクタム系抗菌薬（アズトレオナム含む）を分解する。

IMP（クラスB）

  • イミペネム（IMP）を分解することから命名されたMBL。
  • 日本国内のCPEではIMP型が大半を占める。

NDM（クラスB）

  • New Delhi metallo-β-lactamase。インドで報告され世界中に拡散。
  • 海外のCPEの主流の一つ。日本でも海外渡航歴のある患者などから検出される。

治療・検査の視点：クラスA/D と クラスB の違い

  • 検査：クラスB（MBL）は活性に亜鉛が必要なため、EDTAなどのキレート剤で阻害される。この性質を利用してMBLを同定する（クラスAのKPCではボロン酸系阻害薬が用いられる）。
  • アズトレオナム：MBLには分解されないが、KPCは分解する。MBL産生菌にESBLなどを同時に持つ場合は無効になり得るため、他剤との併用や阻害薬配合薬が検討される。
  • 新規β-ラクタマーゼ阻害薬配合薬：有効な酵素クラスが薬ごとに異なる（セリン酵素に有効でもMBLには無効なもの、など）。 クラスの同定が薬剤選択に直結する。

ビブリオ科（Vibrio 属）

細菌学的特徴

  • グラム陰性のコンマ状（湾曲）桿菌。極鞭毛で活発に運動する。
  • オキシダーゼ陽性（腸内細菌目との鑑別）。
  • 多くは海水・汽水域に生息し、塩分を好む（好塩性）。コレラ菌は塩分がなくても発育できる。
  • 選択培地：TCBS寒天（コレラ菌は黄色、腸炎ビブリオは緑色のコロニー）。

臨床上のポイント

  • 感染経路：汚染された水・生魚介類の摂取、海水曝露による創傷感染。
  • 患者背景（肝疾患、免疫低下）で重症度が大きく変わる菌種がある。
  • 水様性下痢では脱水の補正（輸液）が治療の基本。

Vibrio cholerae
（コレラ菌）

  • コレラ毒素による大量の水様便（米のとぎ汁様）、重症脱水。
  • O1・O139 血清群が流行を起こす。
  • 海水だけでなく淡水でも生存する。
  • 感染症法で3類。

Vibrio parahaemolyticus
（腸炎ビブリオ）

  • 夏季の生鮮魚介類による食中毒の代表。
  • 好塩性のため、真水（水道水）での洗浄が有効な予防の一つ。
  • 急性胃腸炎（下痢・腹痛・発熱）。

Vibrio vulnificus
（ビブリオ・バルニフィカス）

  • 肝疾患・鉄過剰・免疫低下の患者に重症化しやすい。
  • 生の魚介類の摂取や、傷口への海水曝露で感染。
  • 敗血症と、数時間〜数日で進行する壊死性軟部組織感染症（いわゆる「人食いバクテリア」と呼ばれることがある）。
  • 疑ったら速やかな抗菌薬投与と外科的デブリードマンを検討。

エロモナス科（Aeromonas 属）

細菌学的特徴

  • ビブリオ科に似るが、淡水（河川・湖沼・泥・下水）に生息し、塩分を必要としない。
  • オキシダーゼ陽性、ブドウ糖を発酵。
  • 魚類の病原菌としても有名。
  • 代表菌種：A. hydrophila、A. caviae、A. veronii（biovar sobria）。

臨床像

  • 汚染された淡水に触れた外傷後の軟部組織感染症（壊死性筋膜炎に至ることもある）。
  • 汚染水・食品の摂取による感染性腸炎（水様性〜粘血便）。
  • 肝硬変・悪性腫瘍などの宿主では菌血症を起こすことがある。
  • アンピシリンに自然耐性。
